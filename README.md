# Draggable To-Do List

A fully interactive task management app with drag-and-drop functionality, organized into three categories: To Do, Doing, and Done.

## Features

- **Drag & Drop Tasks** - Move tasks between categories by dragging
- **Three Categories** - Organize tasks into To Do, Doing, and Done columns
- **Drag-to-Delete** - Drag any task to the trash icon to remove it
- **Local Storage** - Tasks persist across browser sessions
- **Clear All** - Button to clear all tasks and reset localStorage
- **Responsive Design** - Works on different screen sizes

## How It Works

1. **Add Tasks** - Enter a task and it appears in the "To Do" column
2. **Drag Tasks** - Click and drag tasks to move them between columns
3. **Delete Tasks** - Drag any task to the trash icon to remove it
4. **Clear All** - Click the clear button to remove all tasks
5. **Persistent Storage** - All tasks are saved locally and restored on page reload

## Installation

1. Clone the repository:
```bash
git clone https://github.com/nakibj/draggable-todo.git
```

2. Open `index.html` in your browser

That's it! No build process needed.
